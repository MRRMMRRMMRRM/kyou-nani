# 今日は何をする日

毎日一枚カードを引いて、今日することを決めるページ。
公開先：https://mrrmmrrmmrrm.github.io/kyou-nani/

## ファイル

| ファイル | 中身 |
|---|---|
| index.html | ページ本体 |
| odai.json | お題の一覧（Web版とアプリで共通） |
| ogp.png | Xなどに URL を貼ったときに出るカード画像（1200×630） |
| apple-touch-icon.png | ホーム画面に追加したときのアイコン、ブラウザのタブのアイコン |

リポジトリ名を `kyou-nani` 以外にした場合は、index.html の上のほうにある
「▼ リポジトリ名を変えたら」の4か所を新しい名前に直してください。

## お題の足し方

odai.json の `"batches"` の最後に、まとまりを一つ足します。

```json
{
  "batches": [
    { "from": "2026-10-24", "list": [ "…いまのお題…" ] },
    { "from": "2026-10-27", "list": [ "ふだん言わない人に／「ありがとう」を／言う。" ] },
    { "from": "2026-12-01", "list": [
      "新しいお題を／ここに書く。",
      "もう一つの／お題。"
    ] }
  ]
}
```

- `／` で改行します。縦書きなので、1行は10文字くらいまで、4行まで
- `from` は、そのお題が出るようになる日です。今日の日付なら、次に引く人からすぐ候補に入ります
- お題を消したり書き換えたりしても大丈夫です。すでに引いた人のカードは変わりません
- 数字は全角（「７」など）にすると、縦書きでも立って表示されます
- JSON の書き方に注意：文は `"` で囲む、項目の間は `,` で区切る、最後の項目の後ろには `,` を付けない。間違えるとページにお題が出なくなります
- アプリもこのファイルを読むので、ここに足せばアプリにも出ます（アプリの更新はいりません）

## しくみ

- お題は、カードを引いたときにランダムで決まります。人によって違うお題が出ます
- ひとりの人には、全部のお題を一回ずつ出し終えるまで、同じお題は出ません（出たお題はその人のブラウザに記録されます）
- 色は曜日で決まります（日＝太陽、月＝月明かり、火＝赤、水＝水色、木＝緑、金＝金色、土＝土色）
- 引いたカードとお題は、その人のブラウザに一週間ぶんだけ記録されます。その日のうちは何度開いても同じカードです

## 確認用の URL

- `…/kyou-nani/?date=2026-11-03`：その日の色でカードを引いてみる（記録は残りません）
- `…/kyou-nani/?reset`：今日のカードを伏せた状態に戻す
