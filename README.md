# 今日は何をする日

毎日一枚カードを引いて、今日することを決めるページ。
公開先：https://mrrmmrrmmrrm.github.io/kyou-nani/

## ファイル

| ファイル | 中身 |
|---|---|
| index.html | ページ本体（お題もこの中に入っています） |
| ogp.png | Xなどに URL を貼ったときに出るカード画像（1200×630） |
| apple-touch-icon.png | ホーム画面に追加したときのアイコン、ブラウザのタブのアイコン |

## GitHub Pages での公開

1. GitHub で新しいリポジトリを作る（名前 `kyou-nani`、**Public**）
2. 「uploading an existing file」から、上の3つのファイル（と、この README）をアップロードして Commit
3. Settings → Pages → Build and deployment
   - Source：**Deploy from a branch**
   - Branch：**main** ／ **/(root)** → Save
4. 数分待つと、上の公開先 URL で見られるようになります

リポジトリ名を `kyou-nani` 以外にした場合は、index.html の上のほうにある
「▼ リポジトリ名を変えたら」の4か所を新しい名前に直してください。

## お題の足し方

index.html の `const ODAI = [` のところに、まとまりを一つ足します。

```js
  { from: "2026-12-01", list: [
    "新しいお題を／ここに書く。",
    "もう一つの／お題。",
  ]},
```

- `／` で改行します。縦書きなので、1行は10文字くらいまで、4行まで
- `from` には**明日以降の日付**を書きます。今のひと巡りが終わったあとから、新しいお題も混ざります。今日・明日のお題が途中で変わることはありません
- お題を消したいときは、行を消さずに別の文に書き換えてください（行を消すと、出る順番がずれます）
- 数字は全角（「７」など）にすると、縦書きでも立って表示されます

## しくみ

- お題は日付から決まるので、同じ日に開いた人は全員同じお題です
- 全部のお題を一回ずつ出し終えるまで、同じお題は出ません（46個なら46日でひと巡り）
- 色は曜日で決まります（日＝太陽、月＝月明かり、火＝赤、水＝水色、木＝緑、金＝金色、土＝土色）
- 引いたかどうかは、その人のブラウザに一週間ぶんだけ記録されます

## 確認用の URL

- `…/kyou-nani/?date=2026-11-03`：その日のカードを表示（記録は残りません）
- `…/kyou-nani/?reset`：今日のカードを伏せた状態に戻す
