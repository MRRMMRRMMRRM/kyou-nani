今日なにする日

プライバシーポリシー

最終更新日：2026年11月　運営者：まいら

iPhone・iPad アプリ「今日なにする日」（以下「本アプリ」）は、利用者のプライバシーを尊重し、個人情報の保護に努めます。

収集する情報

本アプリは、氏名・メールアドレス・電話番号・位置情報などの個人情報を収集しません。アカウントの登録もありません。

本アプリが保存する情報

本アプリは、次の情報を保存します。

  • 引いたカードのお題と、引いた日時
  • 利用者が書いた「ひとこと」
  • 夜のお知らせのオン・オフと時刻

お題・日時・ひとことは、お使いの端末の中と、利用者ご自身の iCloud（Apple のサービス）に保存されます。iCloud に保存するのは、同じ Apple アカウントでサインインしている iPhone や iPad で、同じ記録を見られるようにするためです。iCloud に保存された記録は、利用者ご本人の Apple アカウントでしか読むことができず、運営者が見ることはできません。

お知らせの設定は、お使いの端末の中にだけ保存されます。

通信について

  • お題の一覧を最新の状態にするため、運営者が GitHub Pages（GitHub, Inc. のサービス）に置いているお題のファイルを読み込みます。このとき、本アプリから利用者の情報を送ることはありません。ただし、一般的な Web サイトへのアクセスと同じように、GitHub がアクセス元の IP アドレスなどを記録する場合があります。
  • iCloud との同期は Apple の仕組みで行われ、Apple のプライバシーポリシーが適用されます。

夜のお知らせについて

夜のお知らせは、お使いの端末の中で予約して表示するものです。運営者のサーバーから送るものではありません。お知らせは、端末の「設定」からいつでも止められます。

X などへの共有について

「Xで宣言する」を押すと、X（旧 Twitter）の投稿画面が開きます。共有ボタンを押すと、iPhone・iPad の共有画面が開きます。どちらも、投稿や送信をするかどうかは利用者が決めるもので、本アプリが自動で投稿・送信することはありません。投稿した内容には、投稿先のサービスのプライバシーポリシーが適用されます。

第三者への提供・広告・解析

本アプリは、広告や、利用状況を分析するためのツールを使用していません。利用者の情報を第三者に提供することもありません。

なお、利用者が端末の設定で「App デベロッパと共有」をオンにしている場合、本アプリが異常終了したときの報告（クラッシュ情報）が、Apple を通じて運営者に届くことがあります。この報告は、不具合を直すためにだけ使います。

記録の削除

  • 端末の中の記録は、本アプリを削除すると消えます。
  • iCloud に保存された記録は、iPhone・iPad の「設定」→ 自分の名前 →「iCloud」→「アカウントのストレージを管理」→「今日なにする日」から削除できます。

本ポリシーの変更

本ポリシーの内容を変更する場合は、このページでお知らせします。

Web版について

Web版の「今日なにする日」（このサイト）では、引いたカードとお題を、お使いのブラウザの中にだけ記録します。記録は1週間ほどで消え、運営者に送られることはありません。ページの表示のために、Google Fonts（Google のサービス）から文字の形（フォント）を読み込みます。このとき、GitHub や Google が IP アドレスなどのアクセス情報を記録する場合があります。
